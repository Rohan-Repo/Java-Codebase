# Java-Codebase

A collection of sample Java codes demonstrating modern Java concepts and best practices. Use this repository for quick reference on key Java topics and patterns.

## Features

- **Date and Time API** (java.time)
- **Object-Oriented Design:** Inheritance, Polymorphism
- **Collections Framework:** Lists, Sets, Maps, Queues
- **Generics:** Type-safe reusable code
- **Streams and Method References:** Functional-style data processing
- **Records:** Immutable data carriers (Java 16+ examples included)
- **Optionals:** Handling of null and absent values
- **JDBC:** Database connectivity and SQL operations
- **JUnit:** Unit testing
- **REST API:** Core Java and Maven-based client/server examples

## Project Structure

- Code samples are organized by Java topic.
- Maven is used for project and dependency management.

## Topics Covered

- DateTime API
- Inheritance & Polymorphism
- Collections Framework
- Generics
- Streams & Method References
- Records
- Optionals
- JDBC (Database Access)
- JUnit (Testing)
- REST API Usage
